## First public release

SubtitleForStream adds local live captions to streaming scenes on Windows 11 x64. It supports multiple microphones and selected Windows applications, per-source captions, automatic recognition in the original spoken language, SmartText presets and exceptions, a configurable OBS browser overlay, and a system tray menu.

### Install

Download and run `SubtitleForStream-Setup-0.1.0-x64.exe`. The app installs for the current Windows user and can create a Desktop shortcut. Start with **Transcription → Automatic (CPU baseline)** and Whisper `tiny`. The model needs an Internet connection on first use and can be reused offline.

For OBS, see the [setup instructions](https://github.com/tonythewizard/SubtitleForStream/blob/v0.1.0/README.md#set-up-obs).

### Compatibility and known limits

- This is the first public build. The GitHub workflow tests the software and checks installation, application startup and the local overlay. Microphone-to-OBS qualification and cross-machine GPU testing are tracked separately.
- CUDA and Vulkan are optional. This installer does not bundle the complete NVIDIA CUDA/cuDNN runtime or the Vulkan server and GGML model. CPU is the baseline.
- Application audio capture depends on the Windows process and device configuration. One Discord source represents the mixed call audio.
- The installer is unsigned. Check the published SHA-256 file before running it.
- A previous internal installation with version 0.2.0 will not be offered v0.1.0 by the updater.
