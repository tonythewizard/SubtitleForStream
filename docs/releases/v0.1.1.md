## SubtitleForStream v0.1.1

- Stop and restart now wait for the previous transcription workers to finish. Late captions and Qwen revisions from a stopped session are discarded.
- The ASR queue prioritizes finals and shares processing time between active sources. When the queue fills, it favors keeping finals from less represented sources.
- Audio resampling preserves filter continuity between capture blocks. The OBS overlay waits for changes and still supports ordinary snapshot requests.
- Optional Qwen revisions yield between tokens when Whisper needs the decoder. Invalid responses leave the Whisper caption visible.

Install `SubtitleForStream-Setup-0.1.1-x64.exe` on Windows 11 x64. The installer is unsigned. The release includes a SHA-256 checksum. CUDA and Vulkan require their compatible runtimes. Systems running the older internal v0.2.0 build will need to install this release manually because its version number is lower.

The maintainer confirmed the live checks. In the local two-source synthetic replay, Whisper medium delivered finals on CUDA. Medium on CPU and RX 570 Vulkan exceeded the clip age limit under that load. CPU tiny passed the earlier replay. The performance notes describe the measured scope and the opt-in OBS Browser Source diagnostic.
